
## 🚀 使用方式

1. 将本仓库克隆或下载到本地。
2. 直接用浏览器打开 `index.html` 即可使用（无需服务器）。
3. 或部署到任何静态 Web 服务器（如 GitHub Pages、Vercel 等）。

## 🛠️ 自定义

- **修改默认网站**：编辑 `js/main.js` 中的 `DEFAULT_DATA` 对象。
- **调整样式**：修改 `css/style.css`。
- **增加分类**：在 `DEFAULT_DATA.categories` 中添加新对象。

## 💾 数据持久化

所有增删改操作都会自动保存在浏览器的 `localStorage` 中，刷新页面或关闭浏览器后数据依然存在。

## 📦 部署到 GitHub Pages

1. 在 GitHub 新建仓库（例如 `my-nav`）。
2. 将本文件夹所有内容上传。
3. 进入仓库 Settings → Pages → 选择 `main` 分支 → 保存。
4. 等待几分钟，即可通过 `https://你的用户名.github.io/仓库名` 访问。

Enjoy! 🌿
